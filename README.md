Entry for the make.fun bounty "The One-Liner Groan-Off": one original one-line dad joke (at most 140 characters), judged pairwise by an AI judge on how well it lands as a dad joke, punchline speed, freshness, tightness, and groan.

## Run it

Requires Node 22.18 or later (TypeScript runs as-is). On Node 22.6 to 22.17 use `node --experimental-strip-types main.ts`.

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` and verifies it byte for byte.
